# 模组接入 APP 测试指导

**目标 APP：PuroFit**　　**文档版本：V0.1**

本文面向客户硬件 / 固件工程师，说明如何安装 APP、进入测试入口、连接模组并核对关键信息。

---

## 1. 快速开始

- [ ] 安装 PuroFit，并授予蓝牙、定位权限
- [ ] 打开「设置 → 关于」，连点“FIT”logo 5 次并输入密码解锁 Debug
- [ ] 在 Debug 中打开「蓝牙助手快速入口」
- [ ] 首页点击「标题」进入蓝牙助手，选择器材类型
- [ ] 点击「扫描」，连接模组，确认连接状态为「已连接」
- [ ] 核对实时数据与设备信息

---

## 3. 纯蓝牙测试入口（蓝牙助手）

PuroFit 内置「蓝牙助手」调试入口，可直接扫描、连接模组并查看 BLE 上报的实时数据，用于模组射频与数据链路自测。

```{raw} html
<video src="../_static/video/purofit-bluetooth-entry.mp4" controls playsinline width="280" style="display:block;margin:0 auto 1em;"></video>
```

> 上方为「我的 → 设置 → 关于 → 解锁 Debug → 打开**蓝牙助手快速入口**→ 首页 → 标题（蓝牙助手快速入口）」的完整操作录屏。

### 3.1 入口路径总览

| 步骤 | 操作 | 页面位置 |
|---|---|---|
| 1 | 进入设置 | 我的 → 设置 |
| 2 | 解锁 Debug | 设置 → 关于 → 连续点击“FIT”logo 5 次 → 输入密码 |
| 3 | 开启快速入口 | 设置 → Debug → 打开**蓝牙助手快速入口** |
| 4 | 进入蓝牙助手 | 首页点击顶部「标题」 |
| 5 | 选择器材类型 | 跑步机 / 单车 / 椭圆机 / 划船机 / 爬楼机 |
| 6 | 扫描并连接 | 「扫描」→ 设备列表 → 点击目标设备 |

> 蓝牙助手快速入口是一次性开关，开启后长期有效，无需每次重复解锁。

### 3.2 解锁 Debug 菜单

1. 打开「我的 → 设置」。
2. 点击「关于」，进入关于页。
3. **连续点击“FIT”logo 5 次**，弹出「请输入密码」对话框。
4. 输入测试密码后，点击「确认」。
5. 校验通过后进入 Debug 菜单。

> 关于页同时提供「服务协议 / 隐私政策 / 会员协议」入口，与测试无关。

### 3.3 开启蓝牙助手快速入口

1. 设置页进入 Debug 菜单。
2. 打开 **蓝牙助手快速入口** 开关。
3. 说明文字为「开启后首页点击“标题”可快速进入蓝牙助手页面」。

| 开关 | 作用 |
|---|---|
| 蓝牙助手快速入口 | 首页标题可点击，直接跳转蓝牙助手 |

### 3.4 进入蓝牙助手并选择器材

1. 返回 APP 首页。
2. 点击顶部 **标题**，进入「蓝牙助手」页。
3. 按被测设备选择器材类型：

| 器材类型 | 适用场景 |
|---|---|
| 跑步机 | 跑步机模组联调，含速度、坡度、距离、卡路里、时间等 |
| 单车 | 健身车模组联调，含功率、踏频、距离、卡路里、时间等 |
| 椭圆机 | 椭圆机模组联调，含功率、踏频、距离、卡路里、时间等 |
| 划船机 | 划船机模组联调，含功率、桨频、距离、卡路里、时间等 |
| 爬楼机 | 爬楼机模组联调，含步数、步频、距离、卡路里、时间等 |

4. 选择后进入「蓝牙调试工具」页，页面标题显示所选器材类型。

### 3.5 扫描并连接模组

1. 确认模组已上电并完成初始化。
2. 手机打开蓝牙；Android 11 及以下还需打开系统定位。
3. 在调试工具页点击「扫描」。
4. 等待设备列表出现目标设备，核对名称。
5. 点击设备发起连接，顶部「连接状态」由 **未连接** 变为 **已连接**。

连接成功后即可在页面查看模组上报的实时数据；断开时状态回到「未连接」。

### 3.6 调试面板字段

以跑步机页为例，页面包含以下字段：

| 分组 | 字段 |
|---|---|
| 连接 | 连接状态、扫描按钮、设备列表、设备、设备状态 |
| 速度 | 瞬时速度（Km/h）、瞬时配速（min/km）、平均速度（Km/h）、平均配速（min/km） |
| 坡度 | 坡度、坡度角设置 |
| 热量 | 每小时热量（kcal）、每分钟热量（kcal）、热量（kcal） |
| 时间 | 已用时间、剩余时间 |
| 里程 | 总距离（米）、步数 |
| 其他 | 功率输出（W）、心率（bpm）|

> 字段以模组实际上报为准，未上报的字段显示为空或 0 属正常现象。

「设备」「设备状态」的含义与蓝牙芯片信息的详细说明见 [4.3](#43-设备信息)。

### 3.7 该入口的适用范围

- 适用：BLE 连接性验证、数据上下行核对、单位与量程核对、现场快速判定模组是否正常。
- 不适用：账号、课程、云端运动记录等业务功能，这些需走正式业务流程。
- 该入口只用于 BLE 连接与数据观察，器材 MCU 与模组的串口握手仍需按协议单独验证。

## 4. 关键信息查看与常见问题

### 4.1 连接状态

- 调试页顶部显示当前连接状态：**未连接 / 已连接**。
- 未连接时点击「扫描」，在设备列表中选择目标模组，连接成功后状态变为「已连接」。
- 断开或退出调试页后状态回到「未连接」，需重新扫描连接。

### 4.2 器材数据

调试页按所选器材展示实时数据，字段见 [3.6](#36-调试面板字段)。核对要点：

- 数值应随器材动作实时变化；长时间不变说明未收到模组上报。
- 器材未上报的字段显示为空或 0，属正常现象。
- 与器材本体显示对比，出现固定偏差时先检查器材侧单位与量程设置。

### 4.3 设备信息

调试页顶部显示当前连接状态与设备名称；点击「设备」进入「设备信息」页，可查看以下内容：

| 查看位置 | 可查看内容 |
|---|---|
| 调试页顶部 | 连接状态（详见 [4.1](#41-连接状态)）、设备名称、设备状态 |
| 设备信息 → 蓝牙芯片信息 | 模组型号、序列号、生产商，以及硬件 / 固件 / 软件版本 |
| 设备信息 → 公有能力 | 模组支持哪些通用数据项，逐项显示支持或不支持 |
| 设备信息 → 目标设定功能 | 模组支持哪些由 APP 下发的目标值，逐项显示支持或不支持 |
| 设备信息 → 支持范围 | 阻力、速度、坡度、功率、心率等参数的取值范围（最小 / 最大 / 步进） |

核对要点：

- 同一场地有多台模组时，务必按「设备」名称区分，避免连错设备。
- 页面显示的条目与取值由模组应答决定，与模组规格不符时，先按 {doc}`../protocol/serial-protocol` 核对设备信息与能力应答。
- 未上报的项显示为 `--`，需确认模组固件是否已实现对应功能。
- 修改设备名称后仍显示旧值属缓存，关闭 APP 后台后重新连接即可刷新。
- 序列号与硬件 / 固件 / 软件版本是定位问题的必要信息，反馈前请截图留存。

### 4.4 反馈材料

反馈问题时请提供：

- APP 版本号（关于页）与手机型号、系统版本
- 调试页截图（连接状态与关键数据）
- 设备信息页截图（序列号与硬件 / 固件 / 软件版本）

### 4.5 常见问题

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 首页标题点不动 | 未开启「蓝牙助手快速入口」 | 设置 → Debug 中打开该开关 |
| 设置里没有 Debug | 未解锁或操作错误 | 关于页连点“FIT”logo 5 次，输入业务提供的密码 |
| 提示「密码错误」 | 密码不正确或已更换 | 向业务或测试负责人重新索取 |
| 扫描不到设备 | 未授予定位权限或系统定位关闭；模组未上电或处于复位 | 打开定位与蓝牙后重新扫描；确认模组供电，具体参考模组规格 |
| 连接失败 | 已被其他手机占用 | 断开其他设备后重试 |
| 连接后立即断开 | 距离过远或天线被遮挡 | 靠近至 1 m 内，远离金属与人体遮挡 |
| 连上但无数据 | 器材未向模组上报数据 | 确认器材侧串口通讯正常后再测 APP |
| 控制无响应 | 器材未响应控制指令 | 确认器材侧串口通讯指令是否正常 |
| 速度或距离数值偏差 | 计量单位与器材设置不一致 | 核对器材侧串口通讯单位设置 |
| 字段显示为空或 0 | 器材未上报该项 | 属正常现象，确认该字段是否可选 |
| 名称或设备信息显示异常 | 修改后未刷新缓存 | 关闭 APP 后台后再次连接查看 |
